## Algoritma

1. Memasukkan nama mahasiswa dan kode kelas.
2. Membersihkan spasi pada nama.
3. Mengubah nama menjadi title case.
4. Memisahkan nama menjadi beberapa kata.
5. Membuat inisial dari huruf awal setiap kata.
6. Mengubah kode kelas menjadi huruf besar.
7. Mengganti spasi pada kode kelas dengan tanda hubung.
8. Menampilkan hasil normalisasi.
